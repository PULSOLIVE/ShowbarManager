# ShowbarManager ERP Complete Ecosystem

Versão Oficial: 1.0.0 Enterprise

O ShowbarManager é um ecossistema ERP/SaaS enterprise para gestão de eventos, ticketing, cashless, bar, POS, KDS, produção executiva, produção técnica, logística, financeiro, fiscal, multiempresa, multi-tenant, white label e operação offline emergencial.

## Stack oficial

Backend: Java 21, Spring Boot, PostgreSQL, Redis, Flyway, JWT, Swagger  
Frontend: React, TypeScript, Vite, Tailwind  
Mobile: Flutter  
Infra local: Docker, PostgreSQL, Redis, MinIO  
Arquitetura: Monólito Modular Inteligente e Evolutivo
